# DauKey — tải về

Bộ gõ tiếng Việt cho **macOS, Windows và Linux (IBus)**.

Tải bản mới nhất ở mục **[Releases](https://github.com/keel-app/daukey/releases/latest)**:

| Nền tảng | File |
|---|---|
| macOS 12 trở lên | `DauKey-<phiên bản>-macOS.zip` — giải nén, kéo `DauKey.app` vào Applications, mở lên và cấp quyền Accessibility |
| Windows 10/11 | `DauKey-<phiên bản>-Windows.zip` — giải nén, chạy `DauKey.exe` |
| Linux (IBus) | `DauKey-<phiên bản>-Linux-IBus.tar.gz` |

DauKey tự kiểm tra bản mới mỗi ngày (tắt được trong Cài đặt → Chung).
