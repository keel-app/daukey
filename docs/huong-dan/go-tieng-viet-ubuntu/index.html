Cách gõ tiếng Việt trên Ubuntu 24.04

Ubuntu chưa có sẵn bộ gõ tiếng Việt. Bài này cài DauKey, một bộ gõ miễn phí cho IBus, rồi thêm vào Input Sources để gõ Telex, VNI hay VIQR. Chạy trên cả Wayland lẫn X11, máy x64 lẫn ARM64. Mất khoảng năm phút.

Cần có
  • Ubuntu 24.04 trở lên (hoặc Fedora 40 trở lên), giao diện GNOME mặc định.
  • Quyền sudo để cài.

1. Tải DauKey

Mở Terminal (Ctrl+Alt+T). Xem máy của bạn là x64 hay ARM64:

uname -m

x86_64 là máy x64 (đa số máy tính), aarch64 là ARM64. Rồi tải đúng bản:

Máy x64

cd ~/Downloads
wget https://github.com/keel-app/daukey/releases/download/v1.0.0/DauKey-1.0.0-Linux-IBus.tar.gz
tar -xzf DauKey-1.0.0-Linux-IBus.tar.gz

Máy ARM64

cd ~/Downloads
wget https://github.com/keel-app/daukey/releases/download/v1.0.0/DauKey-1.0.0-Linux-IBus-arm64.tar.gz
tar -xzf DauKey-1.0.0-Linux-IBus-arm64.tar.gz

Hoặc tải bằng trình duyệt ở trang tải về rồi giải nén.

2. Cài đặt

cd daukey
sudo ./install.sh
ibus restart

Lệnh cài chép DauKey vào hệ thống. ibus restart (không cần sudo) để IBus thấy bộ gõ mới.

3. Thêm DauKey vào Input Sources

  1. Mở Settings → Keyboard.
  2. Ở mục Input Sources, bấm + Add Input Source.
  3. Chọn Vietnamese → Vietnamese (DauKey) → Add.

Hoặc làm bằng một lệnh, giữ bàn phím tiếng Anh và thêm DauKey:

gsettings set org.gnome.desktop.input-sources sources "[('xkb', 'us'), ('ibus', 'daukey')]"

Nếu bàn phím của bạn không phải us, dùng cách qua Settings để giữ nguyên bàn phím hiện có.

4. Gõ thử và chuyển Việt/Anh

Bấm vào ô chữ trên thanh trên cùng (cạnh đồng hồ) và chọn Vietnamese (DauKey), hoặc bấm Super+Space. Ô đó hiện â khi đang gõ tiếng Việt.

Bấm Ctrl+Shift rồi nhả để chuyển qua lại tiếng Việt và tiếng Anh. Ô trên thanh trên cùng đổi giữa â và a, kèm một tiếng báo nhỏ. Các phím của ứng dụng như Ctrl+Shift+T vẫn chạy như thường.

5. Chọn kiểu gõ, gõ tắt

Bấm vào chữ â trên thanh trên cùng: menu có Kiểu gõ (Telex, Telex đơn giản, VNI, VIQR), Bảng mã, bật/tắt Gõ tắt và Kiểm tra chính tả, và Cài đặt….

Trong cửa sổ Cài đặt (cũng mở được từ danh sách ứng dụng, tên DauKey):

  • Phím tắt: đổi phím chuyển Việt/Anh, đặt phím đổi kiểu gõ.
  • Gõ tắt: thêm vn → Việt Nam. Xem cách dùng gõ tắt.
  • Tùy chọn: bỏ dấu kiểu mới (hoà, khoẻ), viết hoa đầu câu, tạm gõ tiếng Anh khi bật Caps Lock.

6. Khi không gõ được

Không thấy Vietnamese (DauKey) trong danh sách

Chạy lại ibus restart. Vẫn không thấy thì đăng xuất rồi đăng nhập lại. Kiểm tra IBus đã nhận DauKey chưa:

ibus list-engine | grep -i daukey
Gõ được ở app khác nhưng không gõ được trong Chrome hay VS Code

Chrome, VS Code và các app Electron chạy bằng Wayland gốc có thể cần bật bộ gõ cho Wayland. Mở app với cờ --enable-wayland-ime, ví dụ google-chrome --enable-wayland-ime. Chạy ở chế độ mặc định (XWayland) thì thường không cần.

Gõ ra chữ có gạch chân rồi mới thành chữ thật

Đó là chữ đang gõ dở: DauKey hiện từ đang gõ có gạch chân và đưa vào ứng dụng khi bạn bấm dấu cách hoặc dấu câu. Cách này chạy được trên mọi ứng dụng, cả Wayland lẫn X11.

Đang dùng một bộ gõ IBus khác

Có thể giữ cả hai, nhưng chỉ chọn một bộ gõ tiếng Việt trên thanh trên cùng để tránh gõ dấu hai lần. Bỏ bộ gõ cũ trong Settings → Keyboard → Input Sources nếu không dùng nữa.

7. Gỡ cài đặt

Bỏ DauKey khỏi Input Sources trong Settings, rồi trong thư mục đã giải nén:

sudo ./install.sh --uninstall
ibus restart
Dùng cả Windows?

DauKey có bản Windows với cùng cách gõ, cùng phím tắt, cùng file gõ tắt. Xem cách gõ tiếng Việt trên Windows.
