Một bộ gõ tiếng Việt, gõ y hệt nhau trên mọi máy.

Cùng cách bỏ dấu, cùng danh sách gõ tắt, cùng phím tắt trên macOS, Windows và Linux. Chuyển máy là gõ tiếp, không phải làm quen lại. Miễn phí.

Điều làm DauKey khác

Những chỗ bộ gõ hay làm phiền người dùng, DauKey xử lý sẵn.

macOS · Windows · Linux

Một bộ gõ cho cả ba hệ điều hành

Cùng một lõi gõ, nên thuowr ra thuở, khuyur ra khuỷu ở mọi máy. File gõ tắt chép từ Mac sang Windows hay Linux là dùng được ngay.

macOS

Không phá chữ trên thanh địa chỉ

Khi trình duyệt đang gợi ý, gõ dấu thường ra nguyeễn. DauKey nhận ra Chrome, Safari, Edge, Firefox, Cốc Cốc… và gõ đúng nguyễn.

macOS · Windows · Linux

Không cướp phím tắt của ứng dụng

Ctrl+Shift chỉ chuyển Việt/Anh khi bạn bấm rồi nhả riêng hai phím đó. Ctrl+Shift+T vẫn mở lại tab như thường.

macOS · Windows · Linux

Nghe là biết đang gõ gì

Bật tiếng Việt và chuyển sang tiếng Anh phát hai tiếng khác nhau, nên khỏi liếc lên thanh menu. Tắt được nếu không thích.

macOS

Tự đứng ngoài máy ảo

Đang dùng VMware, Parallels, UTM hay remote desktop, DauKey để phím đi thẳng vào máy kia, không gõ dấu chồng lên bộ gõ bên trong.

Linux

Linux không phải hàng thứ cấp

Chữ â/a trên thanh GNOME, menu đầy đủ, cửa sổ Cài đặt theo chuẩn GNOME. Gõ qua IBus nên chạy được cả Wayland lẫn X11.

macOS · Windows · Linux

Gõ tắt hiểu chữ hoa

Đặt một lần vn → Việt Nam. Gõ Vn ra Việt Nam, VN ra VIỆT NAM, không phải khai báo ba lần.

Được thử bằng hàng triệu phím

Mỗi thay đổi đều phải qua gần 200 bài kiểm tra chính tả và hàng triệu chuỗi phím ngẫu nhiên trước khi đến tay bạn.

Không gửi đi những gì bạn gõ

Kết nối mạng duy nhất là kiểm tra bản mới mỗi ngày, và tắt được. Không tài khoản, không quảng cáo.

Và đủ những thứ một bộ gõ cần có

  • Telex, Telex đơn giản, VNI, VIQR
  • Bỏ dấu kiểu cũ (hòa) hoặc mới (hoà)
  • Từ tiếng Anh (html, github) giữ nguyên
  • Unicode, TCVN3, VNI Windows, CP 1258
  • Viết hoa đầu câu, tạm gõ tiếng Anh khi bật Caps Lock
  • Đặt phím đổi kiểu gõ, mở cài đặt

Tải về

Bản đầu tiên sắp phát hành. Bấm vào nút để xem trang phát hành.

File .zip. Giải nén, kéo DauKey vào Applications.

Windows

Tải cho Windows

File .zip. Giải nén, chạy DauKey.exe.

Linux

IBus · GNOME, KDE, Wayland và X11

Tải cho Linux

File .tar.gz cho IBus. Xem hướng dẫn cài bên dưới.

Cài đặt

macOS
  1. Giải nén file .zip, kéo DauKey vào thư mục Applications.
  2. Lần đầu mở: chuột phải vào DauKey → Open → Open.
  3. Cấp quyền: System Settings → Privacy & Security → Accessibility → bật DauKey.
  4. Chữ â hiện trên thanh menu là đã sẵn sàng. Cài đặt ở menu → Cài đặt… (⌘,).
Windows
  1. Giải nén file .zip vào một thư mục cố định, ví dụ C:\Program Files\DauKey.
  2. Chạy DauKey.exe. Nếu Windows SmartScreen hỏi: More info → Run anyway.
  3. Biểu tượng â ở khay hệ thống (bấm mũi tên ^ nếu không thấy). Nhấp đúp để mở Cài đặt.
  4. Muốn DauKey chạy cùng Windows: Cài đặt → Chung → Tự động chạy khi đăng nhập.
Linux (IBus)
  1. Cần IBus và (cho cửa sổ Cài đặt) GTK 4 + libadwaita, có sẵn trên Ubuntu 24.04, Fedora 40 trở lên.
  2. Giải nén và cài: 
    tar -xzf DauKey-*-Linux-IBus.tar.gz
cd daukey
sudo ./install.sh
  3. Settings → Keyboard → Input Sources → + → Vietnamese → DauKey.
  4. Chọn DauKey trên thanh trên cùng (hiện chữ â). Menu ở đó có Cài đặt…

Gỡ cài đặt: sudo ./install.sh --uninstall trong cùng thư mục.

Hỏi đáp

Bấm Ctrl+Shift trên Windows thì đổi luôn cả bàn phím của Windows?

Windows cũng có thể dùng Ctrl+Shift để đổi ngôn ngữ nhập. Tắt nó ở Settings → Time & language → Typing → Advanced keyboard settings → Input language hot keys, hoặc đặt phím khác trong Cài đặt → Phím tắt của DauKey.

Gõ không ra dấu trong một vài ứng dụng trên Windows?

Ứng dụng chạy bằng quyền Administrator không nhận phím từ chương trình thường. Chạy DauKey bằng quyền Administrator nếu cần gõ trong các ứng dụng đó.

Gõ trong máy ảo hoặc remote desktop?

Phím được gửi thẳng vào máy ảo, nên hãy cài DauKey bên trong máy ảo. Trên macOS, DauKey tự đứng ngoài khi cửa sổ máy ảo (VMware, Parallels, UTM…) đang được chọn.

Sao gõ www lại ra ww?

Trong Telex, gõ một phím hai lần là huỷ dấu của phím đó (ww → w, coffee → cofee), giống các bộ gõ Telex khác. Dùng kiểu Telex đơn giản nếu bạn hay gõ chữ có nhiều chữ w.

DauKey có thu thập dữ liệu không?

Không. DauKey chỉ kết nối mạng để kiểm tra bản mới mỗi ngày (tắt được trong Cài đặt → Chung). Không gửi những gì bạn gõ đi đâu.
